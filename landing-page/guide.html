Setup Guide

Complete Setup in 5 Minutes

Follow these steps to get instant WhatsApp notifications for every WooCommerce order. No coding needed.

📋 What You'll Do

Step 1 — Create Hugging Face Account Step 2 — Create a Docker Space Step 3 — Upload Backend Files Step 4 — Wait for Build Step 5 — Install WordPress Plugin Step 6 — Connect & Scan QR Step 7 — Send Test Message Step 8 — Done! 🎉
⏱️ Total time: 5 minutes • 🧑‍💻 No coding required • 💰 100% free hosting

✅ Before You Start, You Need:

  • •A WordPress website with WooCommerce installed
  • •WhatsApp on your phone (regular WhatsApp works fine)
  • •An email to create Hugging Face account (free)
  • •The plugin ZIP file (you got after purchase)
1

Create a Free Hugging Face Account

Hugging Face is a free platform where your WhatsApp backend will run.

  1. 1.1Go to huggingface.co/join
  2. 1.2Sign up with your email (or use Google/GitHub login)
  3. 1.3Verify your email if asked
  4. 1.4Done! You now have a HuggingFace account.
💡 Tip: Remember your username — your Space URL will be https://YOUR-USERNAME-spacename.hf.space
2

Create a New Docker Space

This is where your WhatsApp messaging server will live.

  1. 2.1Go to huggingface.co/new-space
  2. 2.2Space name: Type whatsapp-notifier (or any name you like)
  3. 2.3SDK: Select Docker (important! not Gradio/Streamlit)
  4. 2.4Visibility: Choose Private (recommended for security)
  5. 2.5Click "Create Space"
⚠️ Important: You MUST select Docker as the SDK. If you select Gradio or Streamlit, it won't work.
3

Upload the Backend Files

Upload the 4 files we provided to your Space.

  1. 3.1Open your newly created Space
  2. 3.2Click the "Files" tab at the top
  3. 3.3Click "+ Add file" → "Upload files"
  4. 3.4Upload these 4 files from the whatsapp-node-backend folder:
📁 Files to upload:

├── Dockerfile
├── README.md
├── package.json
└── server.js
  1. 3.5After uploading, click "Commit changes to main"
💡 Tip: You can drag and drop all 4 files at once. Make sure all file names match exactly (case-sensitive).
4

Wait for the Space to Build

Hugging Face will automatically build and start your server.

  1. 4.1After committing files, go to the "App" tab
  2. 4.2You'll see "Building..." status — wait 1-3 minutes
  3. 4.3When done, you'll see a dashboard with WhatsApp status
  4. 4.4Copy your Space URL from the browser address bar
Your Space URL format:

https://YOUR-USERNAME-whatsapp-notifier.hf.space

Example: https://rajesh-whatsapp-notifier.hf.space
⚠️ Note: If you see "Runtime error" — check that you uploaded all 4 files correctly and selected Docker SDK. Try re-uploading.
5

Install the WordPress Plugin

Upload the plugin ZIP to your WordPress site.

  1. 5.1Login to your WordPress admin panel
  2. 5.2Go to Plugins → Add New → Upload Plugin
  3. 5.3Click "Choose File" and select the whatsapp-order-notifier.zip file
  4. 5.4Click "Install Now"
  5. 5.5Click "Activate Plugin"
  6. 5.6You'll be redirected to the plugin dashboard automatically
💡 Requirement: WooCommerce must be installed and active. The plugin will show an error if WooCommerce is not found.
6

Connect to HF Space & Scan QR Code

Link your WordPress plugin to your backend and authenticate WhatsApp.

  1. 6.1In WordPress, go to WhatsApp Notifier → Settings
  2. 6.2In "Hugging Face Space URL" field, paste your Space URL
  3. 6.3Enter your WhatsApp phone number (where you want notifications)
  4. 6.4Click "Save Settings"
  5. 6.5Go back to WhatsApp Notifier → Dashboard
  6. 6.6You'll see a QR Code — scan it with your phone!

📱 How to Scan QR Code:

  1. 1. Open WhatsApp on your phone
  2. 2. Tap ⋮ Menu (3 dots) → Linked Devices
  3. 3. Tap "Link a Device"
  4. 4. Point your camera at the QR code on screen
  5. 5. Wait 2-3 seconds — it will connect automatically!
✅ Success: Dashboard will show "🟢 CONNECTED" with your WhatsApp name. If it shows "QR_READY", scan again.
7

Send a Test Message

Verify everything works before going live.

  1. 7.1On the Dashboard, find "Send Test Message" section
  2. 7.2Enter your phone number (with country code, e.g. +919876543210)
  3. 7.3Click "📤 Send"
  4. 7.4Check your WhatsApp — you should receive a test message! 🎉
✅ If you received the message: Everything is working! Real order notifications will come automatically now.
❌ If it failed: Check: 1) QR is scanned, 2) Space URL is correct, 3) Phone number has country code. Try "Refresh" on dashboard.
🎉

You're All Set!

Your store will now send WhatsApp notifications automatically.

🔔 What happens now:

  • ✓New order placed → instant WhatsApp message
  • ✓Product goes low stock → WhatsApp alert
  • ✓Refund requested → WhatsApp notification
  • ✓Cart abandoned → WhatsApp reminder

🔧 Troubleshooting

QR code not showing?

Wait 10-15 seconds and click "Refresh". The backend needs time to generate it after starting.

Status shows "UNREACHABLE"?

Check that your Space URL is correct and the Space is running (not sleeping). Visit the URL directly to check.

WhatsApp disconnected after a while?

Free HF Spaces sleep after 48 hours. Visit your Space URL to wake it up, then scan QR again from the dashboard.

Test message sent but not received?

Ensure: 1) Phone number includes country code, 2) The recipient has WhatsApp, 3) QR status shows "Connected".

Space shows "Runtime Error"?

Go to Space Settings → Factory Reboot. Or re-upload the files making sure filenames are exact: Dockerfile, server.js, package.json, README.md

Want 24/7 uptime?

Upgrade your HF Space to a paid tier ($5/month) to prevent sleeping. Or deploy the server.js on any VPS (DigitalOcean, Railway, Render).
